# 平台协作修复进度（2026-10-10，第三批）

对应 [Issue #14](https://github.com/cat15926/agent-gand/issues/14)及[第二批进度](./platform-collaboration-repair-progress-2026-10-09.md)。第二批已提交并推送至 `origin/main`：`6ceb731`。

## 本批接入

完成可选的首响应/停滞时限，覆盖冻结入口、房间默认、任务草稿、预览以及内置 API 和四种外部执行后端的公共执行路径。工具执行与审批等待暂停停滞时钟，排队/准备不占用模型活动时钟，总时限及租约仍持续约束执行。设置留空保持原行为。详见[模型活动时限与失败诊断](../architecture/execution-activity-timeouts.md)。

补齐外部工作区、账户和客户端准备失败的执行记录，保留阶段与错误，不自动重放失败作用域。原生事件和 API 回调拦截超时后的晚到输出；内置未知消耗继续保留 Token 预约。任务卡优先展示真实失败执行，后续取消和证据采集异常不会盖过该错误。完整多分支因果图仍在后续范围。

修正准备失败落库的并发围栏：被成员准入拒绝的重复请求不能把有效调用的作用域标为失败。旧 CLI 夹具同步现有“规划预览返回不可执行原因”和“活跃重复调用拒绝、完成结果可复用”的规则，保持只读与不可自动重放要求。

## 验证记录

新增超时夹具与独立时钟/stdio 诊断已通过，覆盖配置冻结/漂移、真实流解析的内存 HTTP 响应、晚到输出、未知预算、慢工具、隐藏思考活动、进程收敛、初始化持久化/冷进程读取、上游取消和排队隔离。CLI 完整回归和 SDK/Codex 阶段 B 的 stdio 模拟回归已通过；后者覆盖写入前审批、拒绝/幂等、超时清理、实际临时 Git diff/测试证据及 FAIL → 返工 → PASS。旧业务验收、编排 O1、私密消息和只读续跑回归已通过。类型检查及 Web 构建已通过，构建保留现有较大 bundle 提示。

浏览器工具本次仍因 trusted Node 进程退出无法连接，未计为浏览器交互或视觉验收。SDK/Codex Runtime 控制联合夹具的监听授权和真实模型验收沿用此前未完成状态。本批不声称这些检查已通过。
