## 实现

- 共用类型定义 `AutonomousTaskPolicyV1`、任务 Grant、执行绑定与 v4 Runtime 特征。协议读取器校验根 Run、预算 Run、策略摘要和能力组合，旧执行器拒绝 v4。
- 根编译服务只处理没有既有执行契约的新 Run。原子保存策略、根 Subject 与 Grant；不创建 Dispatch、不调用模型。相同请求幂等，变更请求冲突。
- 子 Grant 绑定真实父 Attempt 和子 Subject，仅可在成员、输入、工具、动作、输出与有效期上收窄。可委派工具与协调者本人的工具分别记录，避免把安排写入者误当成协调者获得写权限。
- 私密原始目标不扩大范围；不透明转交引用不等于读取正文。来源 ACL/版本、责任代际、停止/过期和祖先撤销每次重验。
- API 与原生沿用现有同一根 Run 及 callId 的 Token/费用账本。根并发与请求模型/驱动绑定在实际调用前检查；未知占额继续阻断后续请求。
- 新管理能力接口要求认证/no-store，明确返回 executionAvailable=false。新配置默认 closed；execute 配置也不绕过尚未交付的调度器。
- Schema 18 只追加策略、Grant、Attempt 绑定和撤销表，含不可变及血缘约束；旧迁移清单不修改。
