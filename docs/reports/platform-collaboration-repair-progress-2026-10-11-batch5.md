## 本批实现

- 失败任务新增 Owner 阶段续跑预览和确认。新步骤图移除已验收阶段及失败阶段中已完成的成员步骤；仅派发未完成任务，后续阶段仍须用户验收。
- 原报告、验收决定、Run/Attempt/阶段来源和证据哈希保持可追溯。新的追加验收不伪造旧执行；原终态、计划、Attempt 和账本不改写，关联后原账本封存。
- 已确认输出与已验收必要文件归档到不可变检查点，哈希冻结到 Run 快照。新 Run 使用独立目录，不复用原目录或失败部分变更；文件漂移、链接、冲突、损坏/缺失检查点和未知结果均阻止执行。
- 原 Run/阶段的硬输出预算占用结转，额度耗尽或未知消耗时阻断续跑。新时间额度在预览中明确告知；Owner 确认后才建立新会话。
- 新增编排迁移 v4；Owner Cookie/CSRF/Origin/Host 边界、提交幂等、预览漂移及旧公共入口防绕过均已接入。页面显示继承阶段、文件和预算说明。
