# 平台协作剩余计划 R1 验收记录（2026-10-11）

对应[剩余实施计划](../plans/platform-collaboration-remaining-implementation-plan.md)与[Issue #14](https://github.com/cat15926/agent-gand/issues/14)。R1 补齐失败关系诊断及本地联合回归；R2–R8 尚未实施完成。

## 交付

- 新增只读失败报告及任务卡诊断面板，关联 Run、事项、Attempt、执行、控制动作和事件；分别展示原始失败、依赖影响、后续停止、未知工具结果及证据采集异常。
- 终态事务保存关闭前的失败与未完成事项快照。关闭过程批量更新为失败的事项不被误报为新的原始故障；后续取消不覆盖失败成员及其恢复分类。
- 明确区分同次调用关联、依赖和实际 AbortReason，多个独立失败均保留；历史重试、控制候选及缺失终局事件不会被推断为本次原始工具故障。
- 模型 API 错误保留已观测的 HTTP 状态和合法 Request ID，正文脱敏；超时记录触发时限、首次和最后可信活动。没有供应商证据的原因仍保持不确定。
- 诊断节点、链接及派生集合按现有成员信息边界过滤；所有者可审计私密记录，其他成员不能取得私密诊断或其引用。查询不修改原记录。
- 修正 Runtime C 模拟消息缺少 SDK message ID、私密咨询缺少必填 `join` 的夹具用法；生产解析和权限规则保持严格校验。

当前生效契约见[Run 失败关系诊断 v1](../architecture/run-failure-diagnostics-v1.md)。没有数据库迁移，也没有扩展私密/写入恢复准入。

## 验证边界与后续

上述使用临时数据库、工作区和模拟推理，没有调用真实 Claude/GLM/Codex 账户。本地网络与原生驱动载体已分别验证，不能等同于 R8 的真实供应商长链路验收。

历史 Run 没有关闭前快照时，只展示已记录的失败及明确关联，不补造终止因果。未知工具副作用仍阻断自动恢复；完整文件 ACL、私密用户入口、工作树快照与费用治理继续由 R2–R7 跟踪。下一阶段为 R2 私密交互与文件权限。

本报告记录本地实现与验证结果；提交与推送状态以 Git 历史为准。
