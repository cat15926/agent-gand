| 场景 | 验证结果 |
|---|---|
| 普通审阅汇总 | A/B 结果进入新的真实汇总 Subject/Scope，实际输入账本有两次授权读取；组织者合法续跑后一次交付，无用户决策 |
| 私密结果返回 | 互不开放的结果直接组成仅 Owner 可见的最终报告；组织者及兄弟成员未收到私密原文；原始 ACL 保持不变 |
| 新增读取者 | 一次确切 intake；未认证、无 CSRF、改变指纹、普通文字“同意”均失败；批准后建立精确副本，实际汇总读取，重复批准无重复副本 |
| 越界发布 | 批准只发布冻结文字和范围；final 等验收；拒绝后换 commandKey 重试也不再次提问，自动回到合法私密交付 |
| 业务提问 | 多个必要问题合并一张卡；重复回答与重复恢复只产生一次唤醒，同 Subject/Run/预算继续 |
| 分支并行 | 生产调度器中一个分支等待业务答案，兄弟分支仍完成；回答后分支与父各恢复一次，共根结算 40 输出 token |
| 阶段/最终输出 | update 立即记录，final 在终局提交；固定状态仅有服务端计数，任意字段与例行继续提问拒绝 |
| 文件交付 | 成员实际写初稿，汇总读取封存版本，再写/读最终文件；正文、工具回执、文件版本及输入 provenance 可对应 |
| 私密文件副本 | 确切授权涵盖报告文件版本，汇总实际读取副本；原材料不进入汇总，原文件 ACL 不变，副本继续追溯已接受结果 |
| 自汇总 | 组织者以新的内容 Subject 读取合法结果，不扩大原 Grant，也不复用其他责任历史 |
| I/O 后校验 | 汇总模型等待期间来源结果被修改，候选及最终发布失败 |
| 新进程恢复 | 已回答但未 wake 的快照由新 Node worker 唯一续跑并交付；已接受根但未 final 的快照无需模型调用即可唯一收尾 |
| unknown 用量 | 根已接受后发现 unknown 调用仍拒绝 final，保留占额 |
| 决策失效 | 来源修改、成员变化、撤销、停止、期限分别拒绝；无副本、批准事实或交付残留 |
| 迁移兼容 | 真正 v19 非空 AC2 夹具重复升级 20，所有旧表行摘要保持；实际旧 worker 拒绝新库，旧根不能升级 |
