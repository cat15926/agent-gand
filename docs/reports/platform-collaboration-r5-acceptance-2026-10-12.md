# 平台协作剩余计划 R5 验收记录（2026-10-12）

R5 已完成现有编排入口和单后继恢复范围的费用预算治理，实现契约见[Run 与阶段费用预算治理 v1](../architecture/cost-budget-governance-v1.md)。实施完成时 R4/R5 均尚未提交或推送，后续提交与推送状态以 Git 历史为准。多分支/跨引擎承接留给 R6，真实供应商联合验收留给 R8；Issue #14 未整体关闭。

## 已交付

- 任务启用费用政策，支持 USD/CNY、Run/阶段上限、计价来源与版本、成员精确模型价格和缓存价格、额外收费项声明。货币无自动转换，价格不自动套用到新模型。
- API 与原生回合调用前原子占额；Token 与费用准入共同事务。并发调用、未知结果和取消后的潜在费用均计入余额。
- 全部未知与部分未知分别保留标记及占额，已知部分单独显示。真实已报告零可以结算，缺失计价或 usage 不冒充免费。
- API JSON/SSE 用量保留输入/输出覆盖信息，缓存分项计价；非法缓存计数和未识别收费字段保留未知。SDK/Codex 只接受当前回合可信费用报告，内部 Token 不用于推定完整原生费用，USD 报告不直接结算 CNY。
- 所有当前后端明确 `estimate_only`，严格账单模式在预览和运行前拒绝。估算超额如实显示并阻断下一次调用；带政策的提交前主管付费规划明确拒绝。
- 重启 pending 预约变未知，不释放信用。连续阶段续跑/整阶段返工、私密写入检查点及只读自由协作续跑保留原政策和已知/未知费用；账本变化、币种/版本变更及耗尽预算不能绕过。
- Owner 预算 API、任务面板、续跑/返工费用预览和审计明细。副作用核对不消除未知费用；费用草稿重开保留，损坏数据阻止派发并提示复核。
- 追加迁移 v9，不重写历史 Run 账单或已有迁移描述。

## 实际边界

估算预约能够控制平台新派发，不能保证供应商实际账单不超过预算。后端报告与按版本计价均独立展示，不冒充供应商账单实测；未知预留是 Owner 决定的占额，不能证明全部未知费用的真实上限。

政策只覆盖提交后的当前 Run 执行。详细主管规划、账户测试、历史无政策任务和平台外调用未纳入费用总表。当前未实现自动供应商价格同步、账户总余额、换汇或后台账单对账。

预算结转目前适用于已开放的关联续跑与整阶段返工。多后继分支、跨引擎检查点、部分成员返工仍由 R6 实施，需复用本费用账本而不能重置额度。SDK/Codex 的供应商计费真实性和真实长链路失败消费验证仍待 R8。
