## 专项验证

`pnpm verify:autonomous-ac5` 与 `pnpm verify:autonomous-ac5-ui` 使用临时库、临时凭据和模拟 Provider，通过产品 HTTP、真实 Scope/Attempt、调度、工具事务及根预算执行。供应商请求与真实原生调用均为 **0**；这不是实际模型策略能力或 SDK/Codex 自主组合的验收。

| 场景 | 核验结果 |
|---|---|
| 完整五人游戏 | 普通发送后自动分配身份、独立夜间行动、白天声明、投票、必要时第二夜至终局；每个决定来自实际工具入口；没有中途用户决策 |
| 信息边界 | 每位玩家仅读自己的身份/查验；主持协调责任不读私密材料；结构化声明是自称；公告重算，终局才披露身份和行动回放 |
| 主持兼玩家 | 5 个既有成员即可；同角色在不同责任冷执行，协调上下文不继承玩家身份 |
| 非游戏流程 | 两位成员读取所选设计，独立表决；同一组件计算固定计数及结论 |
| 普通文件链 | 写入报告 v1→独立读取核对→追加修订→再次读取 v2 复核→实际文件交付；一个 Run、同一预算、零次用户搬运 |
| 非法行动 | 字段/目标错误最多两次纠正，全部记账；原文不公开；连续失败不虚构决定 |
| 终局规则 | 双阵营胜负、座次同票、夜间同时查验、死者/自选/错误阶段/多余字段及终局后推进均核验 |
| 冷进程恢复 | 首阶段接受后暂停，新 Node worker 继续到终局；身份、接受行动、根账本保留；重复恢复不重新发牌或重放 |
| 失败边界 | 私密来源在 I/O 后改变、用户停止、根授权撤销、未知用量、纠正用尽均无虚假终局或最终交付；未知占额保留 |
| 兼容迁移 | 非空 v21 夹具含旧未知占额，两次迁移至22，全部旧表行不变、外键无错；实际 v21 worker 拒绝新库；旧根不能升级 |
| 浏览器 | 一次发送至终局，规则公告直接可见，真实阶段，私密内部记录默认折叠；刷新保留回放；1440px/390px 无横向溢出，页面错误0 |

证据（Git 忽略）：`apps/server/data/autonomous-ac5-qa/result.json`、`apps/server/data/autonomous-ac5-ui-qa/`。

## 后续边界

AC6 仍需真实模型 API/托管 Claude SDK 组合、完整故障与权限矩阵、房间灰度和回退演练。Codex 真实验证按此前用户要求继续暂缓。当前不承诺任意成员故障都能自动换人续局，不支持任意自由文字自动脱密，也不能把成员评审意见等同于用户验收。
