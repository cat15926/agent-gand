# 平台协作剩余计划 R4 验收记录（2026-10-11）

R4 已完成 `stage_gated` Coordination 适用范围的私密及写入恢复实现，生效契约见[私密及写入阶段恢复 v1](../architecture/private-write-stage-recovery-v1.md)，对应[剩余实施计划](../plans/platform-collaboration-remaining-implementation-plan.md)。实施完成时尚未提交或推送代码，后续提交与推送状态以 Git 历史为准。自由协作/其他引擎检查点与多分支承接继续由 R6 跟踪，真实供应商验收留给 R8。

## 已交付

- 公共恢复资格扩展到私密/写入阶段。检查实际进程、Attempt、平台工具、原生独立变更证据、受控文件及授权范围；给出确认完成、可执行剩余步骤、结果未知。
- 所有者核对入口要求依据和外部副作用确认。未知结果默认阻断；已观察到写入的步骤不能被标为未执行后重跑。核对完成正文有明确所有者来源，不篡改原失败 Attempt 或未知工具账本。
- 核对记录不可变且加密，文件/权限/账本变化后失效。Owner 可在任务详情回查核对依据和交付。检查和保存核对均不调模型。
- 阶段检查点 v3 加密保存正文和输出，冻结目标授权与摘要；私密文件按原 ACL 迁移到不可变受控版本，原生目录无私密字节。更窄子范围、权限漂移、未收敛进程和无法验证的产物阻断。
- SDK 与 Codex 可使用平台 `fs.write` 加密完成私密文件任务。写入后继以新目录、新会话承接 Git/文件工作状态，只执行剩余步骤；命令及外部工具在下发和实际执行两处限制。
- 私密和公开写入整阶段返工重新产生交付，并接受新验收。已验收前缀不重放，被拒绝输出不冒充新完成证明。
- 新后继、检查点、文件版本、归档引用、Token 结转、唯一后继及返工原执行关闭保持原子事务。响应丢失和冷重启后的重试复用同一后继；失败整体回滚。
- 未知历史 Token 用 `carried_unknown` 按预留上限保守结转；原未知账本保留，新未知调用仍阻断。写入任务恢复后记录完成步骤的工作区摘要，后续阶段保留合法改动，检测额外漂移而不覆盖。
- 追加迁移 v8，保留 v1/v2 检查点兼容读取与旧 worker 的版本拒绝。

## 限制和后续

当前是冻结阶段图的恢复与整阶段返工。没有开放自由协作/其他引擎的私密及写入检查点，没有部分成员返工、多后继分支或验收清单修订。相关能力仍明确拒绝，继续由 R6 实施，不能将本报告解释为所有编排模式的恢复已完成。

外部副作用由所有者核实或人工收尾，平台不自动证明外部事务是否完成、撤回外部操作或重放命令。后继仅支持受限文件任务；需要命令/外部动作的剩余事项应明确创建新任务，不能通过修改恢复记录绕过。

沿用 R3 限制：单项物理文件/文本 1 MiB、受控文件 256 KiB、完整快照载荷 16 MiB / 4000 条目、额外路径 128 个；检查点正文及元数据 1 MiB。链接、子模块、受保护路径和不可验证 Git 基线拒绝。私密原生文件写入仍关闭，私密字节只通过加密受控版本承接。

R5 继续处理货币预算、未知价格与更完整的费用政策；R6 处理引擎检查点、分支及精细返工；R7 处理调度效率；R8 处理真实 Claude/GLM/Codex 混合后端联合验收。Issue #14 未因此整体关闭。
