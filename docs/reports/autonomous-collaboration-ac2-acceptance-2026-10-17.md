## 隔离验收

`pnpm verify:autonomous-ac2` 已通过。模拟 Provider 经生产调度器和预算入口真实调用 **34 次**，其中新进程恢复 1 次；真实供应商请求 0、真实原生客户端调用 0。这里的模型动作由验收夹具返回，证明执行链路而非真实模型规划质量。

| 场景 | 已验证结果 |
|---|---|
| 动态独立工作 | 主 Agent 的工具参数决定 A/B 不同目标和材料；后续 C 等 A 完成后才派发；父无轮询 |
| 运行中调整 | 第一轮结束后 Agent 追加新目标和既有依赖；不是预填固定批次 |
| 子成员继续协作 | 第二层成员实际调用委派工具，两个父责任分别等待并恢复 |
| 来源隔离 | 主 Agent 不读 A/B 私密材料与结果；兄弟任务隔离；同成员新责任不继承旧私密历史 |
| 跨范围委派 | 读过私密材料的成员向更宽成员发送新 objective 被实际来源门禁拒绝，事务无子工作残留 |
| DAG 与重复 | 循环、自委派、未知依赖、重复工作 key、伪造预算/authority 拒绝；四类图表不可改删 |

| 受控文件 | API 成员实际 fs.write/fs.read，只有一个文件版本、两条成功工具回执，工具结果进入输入账本 |
| 新进程恢复 | 子任务已完成、父未唤醒的快照由新 Node worker 恢复；重复启动只产生一个 wake 和一次父请求，子任务不重发 |
| 来源领取失败 | ACL 漂移在 I/O 前阻断；子责任转失败并生成唯一父唤醒，无无限等待 |
| 请求中断 | 已发出调用租约过期，保留 256 unknown 占额；迟到结果不能提交、派生或释放预算，不自动重发 |
| 用户停止 | 等待父责任、已排队子工作和无 Dispatch 的依赖阻塞节点均关闭；Custody 事件可重放，停止后不再唤醒 |
