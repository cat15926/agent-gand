# 编排入口 O6 验收记录

日期：2026-10-06。结论：O6 本地迁移、兼容、灰度和故障恢复实现完成。真实 Claude/Codex 账户调用属于 O7，本报告没有将 fixture 结果写成真实供应商通过。

## 隔离范围

使用临时旧格式 SQLite、隔离角色目录和 mock 模型；子进程不加载业务 `.env`，禁止供应商 fetch。进程崩溃测试使用实际 Node 子进程及 SIGKILL；仅在测试生成的房间沙箱写入 fixture 文件。测试不重置业务数据库、不启动长期服务、不使用用户 Key、不提交或推送 Git。

## O6 契约和跨进程验收

`pnpm verify:orchestration-o6` 覆盖 13 组行为：

1. 旧 SQLite 增量升级，三个旧 mode 映射；Run、角色快照、工作区、排序时间和原 mode 不变；重复启动不重复迁移。旧无房间 Run 回填保留主管和默认评审者，终态不重跑。
2. 注入房间迁移事务故障，所有房间和审计一起回滚；O5 显式偏好原样收编。
3. 新预览采用旧房间默认；缺主管阻塞；候选团队不受旧 mode 限制；损坏偏好不阻断历史读取。
4. 旧 API 保持响应与弃用提示；关闭新旧入口后同载荷重试返回原任务，冲突 409，新载荷不创建任务。
5. 预览/模板/驱动白名单按实际成员生效；规则预览零调用；关闭时拒绝详细 planner；未知配置值拒绝启动。
6. 所有新任务开关关闭后，另一进程仍完成原冻结步骤图；再次恢复无额外调用、终态唯一；缺契约旧活跃 Run 不重新规划。
7. 回退期间已有暂停图可预览修订，确认后仍暂停，明确恢复后原任务完成。
8. 在模型结果 checkpoint 事务提交后、步骤完成前杀进程；恢复复用结果，只调用后续未执行成员。
9. 调用发出后、结果未记录时杀进程；恢复围栏阻止重放和直接继续。
10. 审批等待期间杀进程；新 worker 重用同一审批卡和已保存工具请求，批准后只写入一次。
11. 实际文件写入后、工具账本提交前杀进程；保留文件和未知执行记录，阻止重放及后续步骤。
12. 只读审计、活跃任务清单及回退检查；拒绝未来 schema 和不支持的活跃快照；审计不包含正文或密钥。
13. 离线维护命令拒绝活服务并发写库，重复映射不产生新任务。

正常服务的宿主身份、成员票据、Coordination/Collaboration 恢复、审批 wake/hold 扫描均用于子进程测试。模型、外部驱动连接和用户审批操作为 fixture；不是用户账户联网验收。

## UI 与回归

`VERIFY_O6_UI=1 pnpm verify:orchestration-o5` 完成 O5 原 11 组验收，并增加一组 O6 页面检查：旧房间转换提示和顺序默认、入口关闭说明、工作流禁用原因、规则预览阻断、零新增 Run/模型调用、390px 无横向溢出。React/浏览器异常为零。依赖 Playwright 与本地 Chromium 路径同 O5 报告。

相关回归：O1 12 组、O3 12 组、O4 11 组；全项目 typecheck、前端生产构建、文档链接及 diff 格式检查。

## 操作边界

- 当前业务数据未被验收脚本迁移；部署本次代码并正常启动后，服务自动映射旧房间默认。
- 开关控制新任务接入，不降低冻结契约。旧格式接口独立开关，完全停止新任务须同时关闭新旧入口。
- 只支持保持 O6 兼容 worker 的接入回退，未验证的旧二进制回退明确拒绝。
- 取消后的未知写入仍需检查，不等于已验证工作区或已撤销文件变化。
- 旧接口清理、用户账户最小真实调用及整体演示留到 O7。
